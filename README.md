# Абылай ханның ішкі саясаты — интерактивті тапсырма

Қазақстан тарихы, 7-сынып. Зерттеу сұрағы: Дербес Қазақ мемлекетін сақтап қалудағы Абылай ханның рөлі қандай?

- **1-тапсырма (3 балл):** саяси әрекет пен мақсатты сәйкестендіру + түсіндірмені тексеру.
- **2-тапсырма (2 балл):** картадан Есіл мен Ертіс өзендерін табу.
- **3-тапсырма (5 балл):** жылнамашы жазбасы. Жазба жауап кілт сөздер мен фактілер базасы бойынша автоматты тексеріледі; мұғалім балды қолмен түзете алады.

Оқушы «Нәтижені мұғалімге көшіру» батырмасымен аты-жөнін, баллын және жауабын көшіріп, мұғалімге жібере алады.

Барлығы бір `index.html` файлында, сервер қажет емес.
